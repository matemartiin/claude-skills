# facultad

Dos skills para el flujo de estudio universitario sobre un vault de Obsidian.

- **`creating-study-summaries`** — resumen de estudio de una materia, construido desde los apuntes de teoría y las guías de práctica. El criterio de completitud es fuerte: con el resumen solo tenés que poder resolver cualquier ejercicio de las guías. Cubre también ampliar, aclarar, auditar y agregar gráficos a un resumen existente.
- **`creating-exam-solutions`** — enunciados de parciales/finales/TPs transcriptos textualmente, con una resolución paso a paso plegable debajo de cada ejercicio, fiel a la resolución de la cátedra.

Convenciones que asumen: LaTeX (`$...$`, `$$...$$`), wikilinks, callouts plegables, Excalidraw para diagramas conceptuales, Chart.js para funciones. Nunca Mermaid.
